# Página de Login

Projeto desenvolvido para a **Prova Individual 01** da disciplina CIC1007 A01 / Projeto I.

O objetivo é praticar o ciclo completo de desenvolvimento com Git, GitHub e GitFlow por meio de uma página de login simples.

## Como executar

Abra o arquivo `index.html` diretamente no navegador ou, no terminal, execute:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Fluxo de branches

- `main`: versões estáveis;
- `develop`: integração do desenvolvimento;
- `feature/pagina-login`: implementação dos campos da página;
- `release/1.0.0`: preparação da primeira versão;
- `hotfix/1.0.1`: correção posterior à publicação.
